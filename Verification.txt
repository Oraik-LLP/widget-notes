WidgetNotes 1.4.0 — Windows x64 verification

CHANGES
- Removed the cached screenshot/pixel-shader renderer and Explorer desktop parenting.
- Uses live Windows compositor acrylic. Interactive movement/resizing uses the lighter native blur state, then restores acrylic afterward.
- Full workspace opens by default as a top-level application with taskbar presence, native resizing, and minimize/maximize/close controls. Compact view remains optional.
- Shared rounded styles cover menus, separators, checkboxes, text fields, dropdowns, scrollbars, dialogs, and confirmation prompts. Settings Save/Cancel stay visible while scrolling.
- Fixed a reproduced menu crash caused by applying a MenuItem style to Separator elements.
- Avoids rebuilding controls or resetting the material on every activation.
- Setup repairs existing WidgetNotes taskbar/startup shortcuts that target older portable copies.
