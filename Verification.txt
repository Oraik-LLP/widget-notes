WidgetNotes 1.5.1 — Windows x64 verification

REPAIR
- Native Acrylic remains visible while the widget is unfocused. The window's compositor appearance and non-client activation appearance are maintained without taking keyboard focus from another app.
- During native move/resize, the blur is disabled and replaced with a soft opaque surface. Content dimensions are held fixed, and autosave scheduling pauses for the gesture.
- The window frame is preserved during pause/resume. The prior WindowBackdropType change rebuilt WindowChrome inside the system gesture loop.
- On release, content reflows once; the native material resumes after a 140 ms settling interval. Preferences are saved afterward rather than during the gesture.
- Composition-change notifications cannot reactivate the blur while a gesture is paused.
- Normal launches remain widget-only, with no taskbar button or application workspace. Startup, tray access, imports, and notebook storage are retained.

LIMITS
- The visual diagnostic uses native gesture messages; continuous physical drag frame cadence was not measured. Tests verify that expensive blur, repeated content reflow, and window-frame recreation are removed from the gesture path.
- This is native Windows frosted Acrylic, not the React liquid-glass refraction shader. The persistent appearance attribute is a native compatibility interface and was verified on this Windows installation.
- The color backdrop, extra windows, animation timer, and taskbar presence exist only for --material-preview with an isolated --test-root. They are absent from ordinary launches.
- The abandoned separate GlassLab diagnostic failed in the restricted execution account. It was stopped and is not shipped in the installer.
- AI import reads selected/dropped local Markdown files; it does not connect to AI accounts automatically.
- Startup registration is checked directly; no sign-out/sign-in cycle was performed.
- The executable is unsigned. No Git remote is configured; the release tag is local and has not published a hosted GitHub release.
