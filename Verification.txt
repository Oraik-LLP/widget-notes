WidgetNotes 1.5.0 — Windows x64 verification

CHANGES
- Widget only: no full application workspace, canvas, maximize action, or taskbar button.
- Native Windows Acrylic through WPF UI 4.3.0 FluentWindow replaces the manual glass setup. No desktop screenshots are used by the renderer.
- WM_ENTERSIZEMOVE pauses the material onto a soft solid surface; WM_EXITSIZEMOVE restores Acrylic. Lock blocks moving and resizing.
- Fixed missing native window hooks when the UI library initialized the HWND before SourceInitialized was subscribed. Initialization now also runs against an existing handle and on Loaded.
- Fixed the reproduced closing exception by deferring save/hide until the native Closing event finishes. Close hides to the tray; menu Exit saves and exits.
- Cards grow with their content inside one vertical scroll area. Removed fixed canvas/card sizing and horizontal scrolling.
- Rounded menus and dialogs share the same styles. Settings applies its backdrop on Loaded, preserves visible Save/Cancel actions, and uses full-width dropdown frames without the inherited ToggleButton styling defect.
- Compact page search, images, attachments, local AI Markdown imports, notebook export, and startup remain available.
- Installer uses Windows Restart Manager for graceful save/shutdown, retains data, installs notices, and repairs shortcuts to older copies.

LIMITS
- WPF screenshots were visually checked for layout and menu/dialog styling. RenderTargetBitmap does not capture the desktop compositor material. Live desktop pixels and motion cadence were not visually verified; native-message tests verify event wiring and material state transitions.
- Windows desktop Acrylic is used; this is not the React liquid-glass refraction shader. System performance/accessibility policy can simplify transparency.
- AI import reads selected or dropped local Markdown files; it does not connect to GPT, Claude, Gemini, or other accounts automatically.
- Startup registration was checked directly; a sign-out/sign-in cycle was not performed.
- The app is unsigned. No remote Git repository is configured; the local release and GitHub Actions workflow do not constitute a hosted GitHub release.
