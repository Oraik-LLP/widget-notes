tagme 1.6.0 — branding release

Renamed the app, executable, tray, installer, release archive and UI to lowercase tagme. Added a yellow frosted sticky-note logo and multi-size ICO. Yellow is the default accent for new preferences.

Existing notebook and settings storage paths retain WidgetNotes for compatibility. Installer recognizes the older installed process, removes the old startup registration, retargets shortcuts and migrates the old .wnote default association.

Build: .NET 10, Windows x64, self-contained. Build succeeded with NU1900 (NuGet vulnerability metadata unavailable).

Isolated verification reports: dist/tagme-storage/self-test.txt, dist/tagme-widget/desktop-test.txt and dist/tagme-ui/ui-test.txt.

The renderer and widget gesture behavior are retained from 1.5.1. No physical drag frame-rate measurement or sign-in cycle was performed for this branding release. The executable remains unsigned.
